О программе и правилах работы

Назначение

Программа помогает специалисту по охране труда вести учёт инструктажей, не пропускать сроки, печатать бланки и вносить данные с бумажных документов. Данные хранятся в обычной книге Excel — по одной на организацию.

Три режима работы

  1. Обычный. Формы в браузере; интернет не нужен.
  2. Excel вручную. Книгу можно открыть в Excel и дополнить, затем проверить в приложении. Пока эта возможность подключается; не открывайте книгу в Excel одновременно с работой программы.
  3. Бумага без компьютера. Заранее печатайте пустые бланки с кодом {{ manual_code }}. Заполните от руки, подпишите, затем внесите через «Внести бумажный бланк».

Что важно помнить

  • Код бланка — только для поиска записи. Он не является подписью и не подтверждает факт проведения.
  • Общий код {{ manual_code }} на пустых бланках одинаков для всех документов и означает ручной режим. Чтобы не внести документ дважды, проверяйте совпадения и вписывайте выданные номера на оригинал.
  • Регистрация означает, что специалист подтвердил наличие подписанного оригинала; программа не проверяет подлинность подписей.
  • Формы бланков, порядок документирования и периодичность утверждает работодатель. Перед внедрением проверьте их по действующим нормативным актам.
  • Перед каждой записью создаётся резервная копия книги.

Где находятся данные

Каталог данных задаётся переменной окружения OTR_DATA_DIR или по умолчанию находится в пользовательском каталоге приложения.

Персональные данные и книги не отправляются в интернет. Программа работает только с этого компьютера.
