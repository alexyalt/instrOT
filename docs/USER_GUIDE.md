# Инструкция для пользователя

Приложение **instrOT** — учёт инструктажей по охране труда. Работает на одном
компьютере без интернета. Данные хранятся в обычном файле Excel, по одному
на организацию.

Кому адресовано: специалисту по охране труда, который ведёт инструктажи
и бумажный архив.

---

## 1. Что нужно для работы

- Компьютер с Windows 10 или 11 (64-bit).
- Microsoft Excel или LibreOffice — чтобы открывать книги вручную.
- Для PDF при печати — LibreOffice (необязательно, см. раздел 9).

Приложение не требует установки Python, интернета и прав администратора.

---

## 2. Запуск и остановка

**Запуск:** двойной щелчок по ярлыку `instrOT`. Откроется браузер с приложением.

**Остановка:** закройте чёрное окно запуска или нажмите в нём `Ctrl+C`.

Что важно знать:

- Окно браузера можно закрыть — приложение продолжает работать. Снова
  запустите ярлык, откроется то же приложение (второй экземпляр не создаётся).
- Все данные остаются на этом компьютере. Ничего не отправляется в интернет.

**Где лежат данные:** `%LOCALAPPDATA%\OTRegistry`. Там книги организаций,
резервные копии, журналы. Эту папку нужно сохранять и периодически копировать
на другой диск.

---

## 3. Первый запуск: создание организации

Каждая организация — отдельный файл Excel со своими работниками, инструктажами,
номерами и архивом. Организации не смешиваются.

1. На главной странице нажмите **«Создать новую книгу»**.
2. Заполните название; остальные реквизиты (ИНН, адрес, руководитель)
   печатаются в бланках — их лучше указать сразу.
3. При желании отметьте **«Добавить демонстрационные данные»** — появятся
   10 работников, 4 допуска и примеры инструктажей с разными сроками.
   Это помогает увидеть, как устроена книга. В рабочей организации такие
   данные можно удалить.
4. Нажмите «Создать книгу».

**Книга создаётся автоматически по шаблону.** Вручную создавать Excel не нужно
и не следует: названия колонок, формулы, выпадающие списки и защита структуры
создаются программой. Это исключает опечатки в названиях, из-за которых
приложение не смогло бы прочитать книгу.

Если книга уже есть (создана этим приложением), используйте
**«Подключить существующую»** и укажите полный путь к файлу.

## 4. Устройство книги Excel

В книге девять листов:

| Лист | Что содержит |
|---|---|
| **Организация** | Реквизиты, настройки, счётчики номеров. Заполняется приложением |
| **Работники** | Список сотрудников с датами рождения и периодичностью |
| **Инструктирующие** | Допуски: кто и по какой программе может проводить инструктаж |
| **Инструктажи** | Все планы и проведённые инструктажи — основной лист |
| **Сводка** | Формулы: сколько запланировано, просрочено, проведено |
| **Архив** | Дела и пакеты: куда подшиваются бумажные оригиналы |
| **Справочники** | Должности, подразделения, программы, причины |
| **История_работников** | Переводы и кадровые изменения |
| **Инструкция** | Памятка по работе с книгой прямо в файле |

**Формулы в книге.** Справа на листе «Инструктажи» две зелёные колонки:
«Дней до срока» и «Состояние» (ПРОСРОЧЕНО / ближайшие / скоро / позднее).
Их не нужно заполнять — они считаются сами при открытии книги в Excel.
На листе «Сводка» — готовые подсчёты по статусам и видам инструктажей.

Приложение считает сроки **самостоятельно**, не полагаясь на формулы: иначе
при правке книги вне Excel подсветка могла бы показывать устаревшие данные.

## 5. Защита структуры книги

Книга защищена паролем: в Excel нельзя изменить названия колонок, вставить
или удалить строки, переименовать листы.

**Зачем:** чтобы случайно не испортить структуру, без которой приложение
не прочитает книгу.

**Пароль** показывает приложение: раздел **«Excel и резерв»**. Он нужен только
для снятия защиты вручную.

Защита — это ограничение от случайных ошибок, **не** средство информационной
безопасности. Пользователь с полным доступом к компьютеру может обойти её.

**Как править книгу вручную:** не снимайте защиту в Excel. Используйте
раздел **«Excel и резерв»** → «Открыть Excel для редактирования» — приложение
само снимет защиту, сделает контрольную копию и заблокирует запись через формы.
После правок: «Проверить и перечитать» → «Принять изменения». Защита вернётся
автоматически.

## 6. Порядок работы

### 6.1. Настройки

Раздел **«Настройки»**: реквизиты для бланков, периодичность повторного
инструктажа (по умолчанию **6 месяцев** — требование Правил № 2464),
пороги подсветки (7 и 14 дней).

### 6.2. Инструктирующие

Раздел **«Инструктирующие»**: добавьте тех, кто проводит инструктажи.

- Укажите ФИО, должность, программу и **срок действия допуска**.
- Отметьте виды инструктажей, которые человек может проводить.
- Один человек может иметь несколько программ — это отдельные строки.

Без действующего допуска инструктирующий не появится в списке при планировании.

### 6.3. Работники

Раздел **«Работники»** → «Добавить работника».

Обязательны: **ФИО, должность и дата рождения**. Дата рождения — обязательный
реквизит регистрации инструктажа по пп. 86, 87 Правил № 2464: без неё
оформление блокируется.

При переводе откройте карточку работника и заполните блок «Перевод» — история
сохранится. При увольнении будущие планы отменятся.

### 6.4. Планирование

Раздел **«Планировать»**: работник, вид инструктажа, дата, инструктирующий.

- Для **всех видов** нужна программа/ЛНА (наименование локального акта).
- Для **внепланового и целевого** дополнительно указывается причина.
- Запись получает **код бланка** — шесть цифр, например `256-541`.

Код печатается на бланке и служит для поиска записи в приложении.
Он не является подписью и не подтверждает проведение инструктажа.

### 6.5. Печать бланков

Раздел **«Печать»**:

- **Заполненные бланки** — отметьте нужные планы и напечатайте.
- **Пустые бланки** — запас для работы без компьютера (раздел 8).

Бланк содержит все обязательные реквизиты, поля для подписей и место
для внесения регистрационных номеров.

### 6.6. Проведение и регистрация

1. Проведите инструктаж, распишитесь оба — работник и инструктирующий.
2. В приложении: **«Регистрация»** → введите код бланка.
3. Проверьте данные на экране.
4. Укажите **фактическую дату** с бланка (не сегодняшнюю, если провели раньше!).
5. Отметьте, что оригинал с подписями у вас на руках.
6. Нажмите «Подтвердить проведение».

Система выдаст номера:

- `ОТ000001` — сквозной;
- `ПВ000001` — по виду инструктажа;
- `Д0001` / `П0001` — дело и пакет.

**Впишите эти номера в поля на бланке** и подшейте документ в папку
соответствующего пакета.

Для **повторного** инструктажа система автоматически предложит следующий
срок — не реже чем через 6 месяцев от фактической даты.

### 6.7. Контроль сроков

Раздел **«Сроки»** — главный экран:

| Цвет | Значение |
|---|---|
| Красный | просрочено |
| Оранжевый | сегодня |
| Оранжевый светлый | ближайшие 7 дней |
| Жёлтый | 8–14 дней |
| Серый | нет даты — нужно уточнить |

Раздел **«Отчёты»** дополнительно показывает:

- записи с неполным набором обязательных реквизитов;
- план повторных на 30 дней;
- истекающие допуски инструктирующих;
- пакеты с количеством документов и реестр каждого пакета.

## 7. Работа с двумя организациями

Переключение — в списке вверху справа. Все действия относятся к выбранной
организации: работники, инструктажи, номера и архив у каждой свои.

Одинаковые номера в разных организациях допустимы, поэтому на бланке всегда
печатается наименование работодателя.

**Если работают два человека:** одна книга — один редактор. Не открывайте
одну книгу одновременно в Excel и приложении. Для второго сотрудника лучше
отдельная книга, иначе потребуется согласовывать время работы.

## 8. Работа без компьютера (бумажный режим)

Когда нет электричества, компьютера или доступа к книге.

**Подготовьтесь заранее:**

1. Раздел **«Печать»** → «Пустые бланки для ручного режима».
2. Выберите вид инструктажа и количество.
3. Напечатайте запас и храните его вместе с папками архива.

На всех таких бланках стоит общий код **000-000** и надпись про ручное
заполнение.

**Во время работы без компьютера:** заполните бланк от руки полностью —
ФИО, должность, подразделение, дату рождения, ЛНА, дату проведения,
инструктирующего. Поставьте обе подписи.

**После появления доступа к приложению:** раздел **«Внести бумажный»**.

1. Выберите работника (или впишите ФИО, если его ещё нет в книге).
2. Введите вид, **фактическую дату с бланка**, инструктирующего, ЛНА.
3. Если этот документ относится к уже созданному плану — выберите его
   в поле «Связать с планом». План завершится, второй записи не появится.
4. Подтвердите наличие оригинала и сохраните.
5. Впишите выданные номера на оригинал.

**Важно:** общий код `000-000` одинаков у всех ручных бланков и не различает
документы. Защита от повторного внесения — это:

- проверка совпадений по работнику, виду и дате;
- номера, вписанные на оригинал после внесения.

Если система предупредит о похожей записи — проверьте её. Если инструктажей
действительно было два в один день, подтвердите это отдельной галочкой.

## 9. Печать: DOCX или PDF

**DOCX** — основной формат: открывается в Word или LibreOffice, печатается
и при необходимости правится вручную.

**PDF** создаётся дополнительно, если установлен LibreOffice. Преимущества PDF:

- одинаковый вид на любом компьютере и принтере;
- файл нельзя случайно изменить при печати;
- удобно хранить и отправлять.

Если LibreOffice не установлен, приложение создаёт DOCX и прямо сообщает,
что PDF не сформирован. **Это не ошибка** — DOCX полностью готов к печати.
LibreOffice нужен, только если вы хотите дополнительно PDF; он бесплатный,
устанавливается отдельно от приложения.

После обновления библиотек печать стоит один раз проверить на принтере:
убедиться, что все реквизиты и места для подписей читаемы.

## 10. Резервные копии

Копия создаётся **автоматически перед каждой записью**, а также перед ручным
режимом, миграцией и обновлением. Хранятся последние 50 копий.

Копии лежат в папке `backups` рядом с книгой организации.

**Обязательно:** периодически копируйте папку с данными на другой диск или
флешку. Копия на том же диске не спасёт при поломке диска.

Раздел **«Excel и резерв»** показывает список копий, даты и размеры.

## 11. Что делать при сообщениях об ошибках

| Сообщение | Что делать |
|---|---|
| «Книга открыта для ручного редактирования» | Закройте Excel → «Excel и резерв» → «Проверить и перечитать» |
| «Файл книги изменён вне приложения» | Откройте форму заново. Если правки были через Excel — проверьте книгу в «Excel и резерв» |
| «Не удалось записать файл: он занят» | Закройте книгу в Excel, повторите |
| «У работника не указана дата рождения» | Дополните карточку работника |
| «Пакет уже закрыт» | Поздно поступивший документ оформляется в новый пакет по порядку |
| «Книга не соответствует формату приложения» | Восстановите файл из резервной копии (раздел «Excel и резерв») |

Проверка окружения: `python scripts/doctor.py` — покажет состояние компонентов.

---

## 12. Чего приложение не делает

- **Не заменяет бумажный оригинал.** Юридически значимый документ — это
  подписанный от руки бланк.
- **Не проверяет подлинность подписей.** Регистрация означает, что вы
  подтвердили наличие оригинала.
- **Не подписывает электронной подписью.** Код бланка — идентификатор поиска.
- **Не утверждает форму бланка.** Форму, порядок регистрации и периодичность
  утверждает работодатель (п. 88 Правил № 2464).
- **Не работает по сети.** Только этот компьютер.
