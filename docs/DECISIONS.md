# Решения и допущения

Дата: 30.10.2026. Редакция соответствует ходу разработки MVP.

## Концепция

| Область | Решение |
|---|---|
| Интерфейс | Локальный веб-сервер на `127.0.0.1`, запуск ярлыком, браузер |
| Хранилище | Один XLSX на организацию; без БД и внешнего сервера |
| Организации | Отдельная книга, свои нумерация, архив, резерв и настройки |
| Пользователи | 1–2 человека; одна книга — один активный редактор |
| Ручной Excel | Контрольная копия, блокировка записи, сверка по ID, принятие правок |
| Бумажный режим | Заранее напечатанные бланки с общим кодом `000-000` |
| Печать | DOCX; PDF при наличии LibreOffice/Word |

## Модель данных

| Решение | Обоснование |
|---|---|
| Постоянный UUID для каждой записи | Сортировка и вставка строк в Excel не ломают связи |
| Работник = одна строка с историей переводов отдельно | Простая структура для 1–2 специалистов |
| Несколько допусков инструктирующего — несколько строк с общим `person_id` | Нет отдельной таблицы программ, но сохраняется разграничение |
| Снимки ФИО, должности, подразделения, даты рождения в инструктаже | Изменение кадровых данных не меняет выданный документ |
| Дело и пакет — строки листа «Архив» | Одна сущность вместо двух связанных таблиц |
| Номера: ОТ000001, ВВ000001, Д0001, П0001 | Понятная выдача без сложной иерархии |

## Сроки и расчёты

| Решение | Обоснование |
|---|---|
| Сроки считает приложение, а не формулы | openpyxl не пересчитывает формулы; кэш может быть устаревшим |
| Формулы Excel допустимы для отображения | Пользователь видит подсветку и в самой книге |
| Периодичность повторного по умолчанию 6 месяцев | П. 87 Правил № 2464: не реже 1 раза в 6 месяцев |
| Периодичность больше 6 месяцев требует основания | Проверка фактического значения, а не только настройки организации |
| Перенос срока — на предыдущий рабочий день | Не выходить за предел; праздничный календарь не ведётся |
| Календарное прибавление месяцев | 31.01 + 1 мес. → последний день февраля |

## Обязательные реквизиты (пп. 86, 87 Правил № 2464)

| Требование | Реализация |
|---|---|
| Дата рождения | Обязательна; снимок хранится в записи; без неё планирование блокируется |
| Наименование ЛНА | Поле «Программа / инструкции», обязательно для всех видов |
| Причина | Обязательна для внепланового и целевого |
| Подписи | Подтверждение наличия оригинала обязательно при регистрации |
| Должность проводившего | Хранится в строке допуска инструктирующего |

## Код бланка и бумажный режим

| Решение | Обоснование |
|---|---|
| Код 6 цифр, показывается как 256-541 | Удобно диктовать и искать; печатается на бланке |
| Код не называется «кодом подписи» | Он не является подписью и не подтверждает проведение |
| Код удаляется из активных, но хранится в истории | Нужен для поиска документа в архиве |
| Общий код `000-000` для пустых бланков | Позволяет печатать запас без создания планов |
| `000-000` не различает документы | Защита от дублей — по работнику, виду, дате и номеру на оригинале |
| При связывании с планом код плана сохраняется в примечании | Не теряется связь с первоначальным бланком |

## Хранилище и надёжность

| Решение | Обоснование |
|---|---|
| Резерв перед каждой записью | Восстановление без сложного журнала транзакций |
| Временный файл + проверка + атомарная замена | Не повредить книгу при сбое |
| Отпечаток SHA-256 перед записью | Обнаружить правки вне приложения |
| Блокировка файла | Не допустить двух одновременных писателей |
| Схема версионируется, миграция с резервом | Обновление не ломает существующие книги |
| Более новая версия схемы — только чтение | Старая программа не испортит новые данные |

## Отклонено

| Вариант | Почему отклонено |
|---|---|
| SQLite или сервер БД | Пользователю нужен Excel как единственный источник |
| Универсальный откат операций | Избыточно; достаточно исправления с причиной и резерва |
| Составной ID как защита от подделки | Он даёт прослеживаемость, а не криптографическую защиту |
| Штрихкоды | Отказ заказчика |
| Сетевой многопользовательский режим | Требует отдельной архитектуры и согласования |
| Автоматическая подстановка 12 месяцев | Не соответствует Правилам № 2464 |
| Молчаливое «обновить отпечаток и продолжить» | Скрывает ошибочные правки в книге |
