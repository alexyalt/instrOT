# instrOT — учёт инструктажей по охране труда

Локальное приложение для специалиста по охране труда: удобный ввод данных, автодополнение,
контроль сроков, печать бланков и учёт нескольких организаций (каждая — отдельный файл Excel).

Работает без интернета на одном компьютере, запускается ярлыком и открывается в браузере
(`127.0.0.1`). База данных — обычный `.xlsx`, который можно открыть и вести вручную.

> Статус: в активной разработке. Версия 1.0 — MVP для 1–2 пользователей.

## Возможности MVP

- **Несколько организаций** — отдельная книга Excel, свои нумерация, архив и резервные копии.
- **Работники** — приём, перевод, увольнение, история кадровых изменений.
- **Инструктирующие** — допуски по программам со сроками действия.
- **Инструктажи** — планирование, регистрация факта по коду бланка, выдача номеров.
- **Сроки** — подсветка просроченных и ближайших (7/14 дней) с текстовой индикацией.
- **Ручной режим на бумаге** — заранее напечатанные пустые бланки с общим кодом `000-000`
  для работы без компьютера и последующий ввод данных в систему.
- **Печать** — заполненные карточки и пустые бланки (DOCX, при наличии LibreOffice — PDF).
- **Excel вручную** — приложение создаёт резерв, блокирует запись и проверяет книгу после правок.
- **Резервные копии и журнал** — перед каждой записью, с понятной процедурой восстановления.

## Быстрый старт (разработчик)

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m ot_registry.launcher
```

Откроется браузер с локальным приложением. Данные по умолчанию создаются в
`%LOCALAPPDATA%\OTRegistry` (Windows) или `~/.otregistry` (Linux/macOS).
Каталог можно переопределить переменной окружения `OTR_DATA_DIR`.

Тесты:

```bash
python -m pytest -q
```

## Структура репозитория

```text
src/ot_registry/          код приложения
  config.py               пути, версия схемы, настройки по умолчанию
  organizations.py        список подключённых организаций
  excel_store.py          чтение/запись XLSX, резерв, блокировки
  schema.py               описание листов и колонок книги
  deadlines.py            расчёт сроков и подсветок
  validation.py           проверки ввода
  services.py             сценарии: работники, планы, регистрация, архив
  printing.py             генерация DOCX/PDF
  web.py                  локальный веб-интерфейс
  templates/, static/     интерфейс
  launcher.py             запуск по ярлыку
resources/forms/          шаблоны бланков
tests/                    автотесты
docs/                     ТЗ, план, решения, журнал работ
user_polls/               вопросы к заказчику и ответы
```

## Важно

Приложение помогает вести учёт и печатать бланки. Оно не подтверждает подлинность подписей и
не заменяет бумажные оригиналы. Порядок документирования, формы и периодичность инструктажей
утверждает работодатель; перед внедрением их нужно проверить по действующим нормативным актам.
